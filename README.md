This is a simple sonar. It uses 24Ghz radio signals that can penetrate walls to sense when something moves it can be something as little as a heartbeat, and sends that to the microcontroller that processes the information and displays it onto the display. It has to be plugged in at all times tho, because it doesnt have a battery, but if you need to, it can most likely draw power from a powerbank or your phone (it draws very little power) The display shows a submarine esk interface with the center and dots as the object that is detected.
