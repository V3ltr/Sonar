This is a simple distance detector. i works by sending out untrasonic sounds to sense if a object is in front of it.
Its very similar to the detecors cars use when you go in reverse and it starts screaming when you get close to a wall.
It uses very little battery but it doesnt have one build in so you have to plug it in.
On the display you see a green dot (thats you) and a red dot infront of you (thats a wall/object in your path) it also shows how far the object is and it works in the dark too!
